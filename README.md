# MORROW Market

一个可直接部署到 GitHub Pages 的演示电商系统，采用无构建前端和 Node.js 原生 HTTP 服务端。界面按高频选购场景组织搜索、实时行情、优惠券、场景楼层和商品目录。

线上商城：<https://1xixin0710.github.io/-1/>

## 功能

- 83 件精选商品、31 个品牌，覆盖手机、电脑、相机、耳机影音、平板、外设和家用电器
- 淘宝式搜索区、热搜词、分类入口、品牌/价格/库存筛选和分页加载
- 每 15 秒刷新一次公开参考价行情，商品卡、主推位和详情价格同步更新
- 商品详情、多规格价格、多色图库、购物袋、优惠券和完整演示结账流程；键盘轴体在单个商品内选择，不拆成重复商品
- AI 导购与售后客服相互独立：AI 导购负责商品筛选与比较，售后客服通过本地规则处理订单、物流、退换和保修
- Node 服务端支持订单创建、库存校验、订单查询和后台管理
- 桌面与移动端响应式布局，商品图使用高分辨率官网图或公开榜单原图

## 本地运行

需要 Node.js 18 或更高版本：

```powershell
node server.js
```

访问：

- 商城：`http://127.0.0.1:4173`
- 订单查询：`http://127.0.0.1:4173/orders/`
- 配送与售后：`http://127.0.0.1:4173/service/`
- 管理后台：`http://127.0.0.1:4173/admin/`

演示管理密钥：`2026`

运行冒烟测试前先启动服务：

```powershell
python tools/system_smoke.py
```

## 数据与部署

`data/catalog.json` 是商品目录源文件，`data/catalog.js` 是供静态页面直接加载的同内容脚本。修改商品后需同步两份文件；当前商品名称、图片和基础价格按公开榜单与品牌页面整理。

GitHub Pages 只托管静态文件，因此线上版本支持浏览、搜索、实时价格演示、AI 导购和浏览器本地结账。Node 管理后台、服务端库存扣减与订单接口需要在本地或支持 Node.js 的环境中运行。

AI 导购使用公共模型接口，可能受限流影响；失败时会自动回退到本地商品筛选建议。
