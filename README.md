# MORROW Market

一个完整的演示电子商务系统，采用 No build 前端和 Node.js 原生 HTTP 服务端。

## 功能

- 54 件 2026 年热门商品，覆盖手机数码、电脑办公、摄影器材和家用电器
- 商品搜索、分类、品牌、价格和库存筛选，支持分页加载
- 商品详情、规格、颜色、数量、购物袋和模拟结账
- 服务端订单创建、库存校验与库存扣减
- 订单编号或邮箱查询，显示商品、金额、地址和履约状态
- 管理后台可调整商品价格、库存、上下架状态和订单状态
- 演示数据重置，状态保存在 `data/store-state.json`
- 响应式设计，支持桌面与移动端

## 运行

需要 Node.js 18 或更高版本：

```powershell
node server.js
```

访问：

- 商城：`http://127.0.0.1:4173`
- 订单查询：`http://127.0.0.1:4173/orders.html`
- 管理后台：`http://127.0.0.1:4173/admin.html`

演示管理密钥：`2026`

## 商品数据

商品名称、图片和参考价按 2026 年 9 月 28 日公开榜单整理。价格会随地区、版本和促销活动变化，页面中明确标注为参考价。

重新抓取商品目录：

```powershell
python tools/build_live_catalog.py
```

## 支付说明

支付系统只包含银行卡、支付宝和微信支付入口，用于展示电子商务流程。不会连接支付平台，不会收集银行卡号，也不会产生真实扣款、订单履约或物流。
